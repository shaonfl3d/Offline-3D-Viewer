3D Viewer for Linux (64-bit)

Run without installing:
    ./viewer3d
    ./viewer3d model.stl

Install for your user (adds a menu entry and "Open With" support):
    ./install.sh
Remove it again:
    ./uninstall.sh

Needs a desktop with OpenGL 3.3 (any normal PC or laptop from the last ~12 years).
Works on X11 and Wayland.
